= smart-cap

smart-cap is a small Java library for capitalizing Italian
business names and addresses. It handles abbreviations, company types,
prepositions, Roman numerals, and URLs.

== Installation

Use JitPack with the `release-2.0.0` tag. Other published tags or commits can also
be used as the dependency version.

*Gradle*

[source,groovy]
----
repositories {
	mavenCentral()
	maven { url = 'https://jitpack.io' }
}

dependencies {
	implementation 'com.github.grational:smart-cap:release-2.0.0'
}
----

*Maven*

[source,xml]
----
<repositories>
	<repository>
		<id>jitpack.io</id>
		<url>https://jitpack.io</url>
	</repository>
</repositories>

<dependency>
	<groupId>com.github.grational</groupId>
	<artifactId>smart-cap</artifactId>
	<version>release-2.0.0</version>
</dependency>
----

== Quick Start

The same application programming interface (API) works from Java and Groovy:

[source,java]
----
import it.italiaonline.rnd.filters.TextFilter;

new TextFilter.SmartCap("ATRES S.R.L.").result();
// Atres S.r.l.

new TextFilter.AddressSmartCap("VIA BOITO ARRIGO,41").result();
// Via Boito Arrigo, 41

new TextFilter.AddressSmartCap("SANTHIA'").result();
// Santhià

new TextFilter.ConditionalSmartCap("G come Di Gioia", 0.85d).result();
// G come Di Gioia
----

== Core API

[cols="1,2",options="header"]
|===
| Type | Purpose
| `TextFilter.SmartCap` | Capitalize Italian business text.
| `TextFilter.AddressSmartCap` | Also fix comma spacing and known town accents.
| `TextFilter.ConditionalSmartCap` | Preserve text when similarity meets the threshold.
|===

Call `result()` to get the text. Null input throws `IllegalArgumentException`.

Conditional capitalization compares the original and capitalized text using
Jaro-Winkler similarity. If the score is at least the threshold, the original
is preserved; otherwise, the capitalized text is returned. A threshold of `0`
always preserves the input; `1` preserves only exact matches.

== Compatibility

Version 2.0.0 is implemented entirely in Java and runs on Java 8 or later.
Production code is compiled with `--release 8`, which checks both the bytecode
target and the Java platform APIs used by the library.

Groovy and Spock are test dependencies only. Applications do not need Groovy
or a logging framework to use smart-cap. Apache Commons Text, and its transitive
dependency Commons Lang, remain runtime dependencies.

The package names, public filter classes, constructors, `result()` methods,
and the town dictionary's `getAccented_towns()` / `setAccented_towns()` accessors
are preserved. `ConditionalSmartCap(String, Double)` retains its boxed `Double`
parameter for existing compiled callers. Groovy applications can continue to
call the library using their own Groovy runtime.

This is a major release because filters no longer implement `GroovyObject`
or expose Groovy-generated metaclass and missing-property methods. Code using
those Groovy-specific hooks must be updated.

Conditional capitalization uses `JaroWinklerSimilarity`, fixing the behavior
with Commons Text 1.10 and later. Earlier smart-cap code depended on
`JaroWinklerDistance` returning a similarity score, an Apache bug corrected in
Commons Text 1.10. The intended rule remains: preserve the original text when
its similarity is at least the threshold.

== Local Development

Use Java Development Kit (JDK) 17 to build, then run:

[source,bash]
----
./gradlew clean build
./gradlew publishToMavenLocal
----

`build` runs the Spock suite and a Java consumer check with production
dependencies only; that check fails if Groovy appears on its class path.

To run both checks on another Java installation while keeping the build on
JDK 17:

[source,bash]
----
./gradlew check -PtestJavaHome=/path/to/java8
----

The checks are verified on Java 8, 17, and 25. JitPack builds on JDK 17 and runs
the checks before publishing.

== Release

Release tags use the `release-` prefix, for example `release-2.0.0`. The Gradle
project version is `2.0.0`; the JitPack dependency version is the complete tag.
After checks pass, push the release commit and tag. Verify that the tagged Java
archive (JAR) and Project Object Model (POM) dependency metadata resolve through
JitPack, and that the published artifact works without Groovy.
